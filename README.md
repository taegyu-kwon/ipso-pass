# 입소 패스

예비군 입소부터 물자 반납까지 절차를 앱으로 관리하는 **시연 프로토타입**입니다.

**웹 체험판: https://ipso-pass.vercel.app** (휴대폰 화면 기준. 오른쪽 위 `시연 패널`에서 날짜·장면을 바꿀 수 있어요)

> 개인이 만든 공모전 출품용 시연작이며, 국방부나 예비군의 공식 앱이 아닙니다.

> **현재 단계: 목데이터 기반 시연용입니다.**
> 업무 서버·DB, 실제 NFC 태그 인식, 본인 인증(로그인) 시스템은 **구현되어 있지 않습니다.**
> 모든 인물·훈련 정보는 앱 안의 더미 데이터(`assets/data/dummy.json`)이며, 네트워크 없이도 전체 흐름을 시연할 수 있습니다.

## 흐름

```
입소 전                    입소 당일                       퇴소
문진 · 서명      →      인증 · 물자 수령        →       퇴소 · 물자 반납
(사전 준비)             (건강 문진 → 입소 태그          (총기 반납 → 장비 반납
 기본 정보 확인          → 카메라 잠금 → 총기 수령        → 카메라 잠금 해제)
 지급 계좌               → 장비 수령)
 동의·서명)
```

- **사전 준비**: 등록 정보 확인, 보상비 지급 계좌, 약관 동의와 손글씨 서명, 제출 전 확인
- **입소**: 건강 문진, 입소 태그로 신원 확인, 카메라 잠금, 총기·장비 수령(장비별 태그)
- **퇴소**: 총기 반납, 장비 반납, 카메라 잠금 해제, 이수 안내
- **담당자 화면**: 훈련장 명단, 태그 등록, 호출
- **시연 패널**: 홈 상단 엠블럼을 길게 누르면 열립니다(웹에서는 오른쪽 위 `시연 패널` 버튼). 인물·날짜·장면을 바꾸고, 태그 실패·NFC 미지원·통신 오류 같은 예외 상황을 고를 수 있습니다.

## 구조

```
화면 (src/app, expo-router)
   │  api.* 만 호출
   ▼
API 계층 (src/api/index.ts, 타입: src/api/types.ts)
   │  지금은 목데이터 반환 · 실제 연동 시 함수 본문만 서버 호출로 교체
   ▼
목데이터 (assets/data/dummy.json)

인증·NFC·카메라 잠금 → 타이머와 시연 패널 설정으로 시뮬레이션
단계 완료 이벤트    → src/lib/board.ts → Apps Script 웹 앱(scripts/board.gs) → 구글 시트 현황판
```

- **화면과 데이터 분리**: 화면은 `@/api`의 함수와 타입만 사용하고, 더미 데이터 파일을 직접 읽는 곳은 `src/api/index.ts` 한 곳뿐입니다. 실제 API로 바꿀 때 화면 코드는 그대로 둘 수 있습니다.
- **시뮬레이션**: 입소·장비 태그는 일정 시간 뒤 인식된 것으로 처리하고(아이콘을 눌러 바로 진행 가능), 결과(성공·실패·미지원·통신 오류)는 시연 패널에서 고릅니다.
- **현황판 연동(선택)**: 각 단계를 마치면 `{ name, step, item }`을 Apps Script 웹 앱으로 보내 시트에서 그 사람 줄의 색과 값을 바꿉니다. 보내기만 하고 응답을 기다리지 않으므로, URL이 없거나 실패해도 앱 흐름은 그대로입니다.

```
src/
  app/          화면 (prep 사전 준비 · entry 입소 · receive 수령 · exit 퇴소 · admin 담당자 · demo 시연 패널)
  api/          데이터 계층과 타입
  state/        시연 진행 상태 (journey)
  lib/          현황판 전송, 햅틱, 개인정보 가림
  ui/ theme/    공통 컴포넌트, 디자인 토큰
scripts/
  board.gs      현황판용 Apps Script
```

## 실행 방법

필요: Node.js LTS, npm. 안드로이드·iOS 실행에는 각각 Android Studio 에뮬레이터·Xcode 시뮬레이터 또는 실제 기기가 필요합니다.

```bash
npm install
cp .env.example .env.local   # 현황판을 쓸 때만. 비워 둬도 동작합니다
npx expo start                # 개발 서버 (i: iOS, a: Android, w: 웹)
```

네이티브 빌드로 실행:

```bash
npm run android
npm run ios
```

웹 정적 빌드:

```bash
npx expo export --platform web   # dist/ 에 생성
```

웹 빌드에서는 현황판 전송을 하지 않습니다(방문자마다 시트를 바꾸지 않도록). Vercel 설정은 `vercel.json`에 있습니다.

### 환경 변수 (.env.example)

| 이름 | 설명 |
| --- | --- |
| `EXPO_PUBLIC_BOARD_URL` | 현황판 Apps Script 웹 앱 URL. 비우면 현황판 전송을 건너뜁니다. `EXPO_PUBLIC_` 값은 앱 번들에 그대로 포함되므로 비밀 값을 넣지 마세요. |

### 현황판 설정 (선택)

1. 구글 시트에 `이름`, `사전준비`, `입소 시간`, `카메라 보안`, `총기`, `물자`, `상태`, 장비 이름 열을 만들고 더미 이름을 넣습니다.
2. 시트 > 확장 프로그램 > Apps Script 에 `scripts/board.gs`를 붙여 넣습니다.
3. 배포 > 새 배포 > 웹 앱(실행: 나, 액세스: 모든 사용자)으로 배포하고, 나온 URL을 `EXPO_PUBLIC_BOARD_URL`에 넣습니다.

URL을 아는 사람은 누구나 시트를 고칠 수 있으므로 실제 개인정보는 넣지 마세요.

## 한계와 다음 단계

- 업무 서버·DB 없음: 제출·인증 기록은 앱 메모리에만 있고, 앱을 다시 열면 처음 상태로 돌아갑니다.
- 실제 NFC 미구현: 태그 인식은 화면상의 시뮬레이션입니다.
- 인증 미구현: 로그인 대신 시연 패널에서 인물을 고릅니다.
- 카메라 잠금은 화면 흐름만 있고 실제 기기 제어는 하지 않습니다.
- 연차별 훈련 로드맵 등 일부 더미 데이터는 예시이며 실제 제도와 다를 수 있습니다.

실제 서비스로 가려면 `src/api/index.ts`의 함수 본문을 서버 API 호출로 바꾸고, NFC 라이브러리(예: react-native-nfc-manager)와 본인 인증을 붙여야 합니다.
